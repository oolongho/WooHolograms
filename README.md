# WooHolograms

🍵 一款多功能、有GUI的 Minecraft 全息文字插件

## 特色

- **多种显示类型**：文本、物品、方块、玩家头颅、自定义实体、翻页按钮
- **视觉效果**：亮度、对齐、背景透明度/颜色、朝向、彩虹渐变
- **动画系统**：波浪、打字机、闪烁、滚动、渐变，支持自定义动画
- **交互功能**：点击动作、行级/页面级动作、冷却
- **性能优化**：Display Entity、增量渲染、对象池、预编译动画
- **Folia 支持**：完整兼容区域化多线程
- **GUI 管理**：可视化编辑，所有功能均可通过 GUI 操作
- **数据迁移**：支持从 HolographicDisplays、CMI、DecentHolograms 导入
- **DH API 兼容**：自动接管依赖 DH API 的插件

## 快速开始

1. 将 `WooHolograms.jar` 放入 `plugins/` 目录
2. 重启服务器
3. 使用 `/wh create <名称>` 创建全息图
4. 使用 `/hologram`或 `/wh` 打开 GUI 编辑
